# himansh97.github.io

Portfolio for Himanshu Srivastava. Three self-contained HTML pages, no build step,
no dependencies, nothing loaded from a CDN.

| Page | What it is |
| --- | --- |
| `index.html` | The front door |
| `pipeline-hero.html` | One CareerOS run as a WebGL2 particle flow — 10,034 postings to 10 applications |
| `containment-gate.html` | The verification layer that decides whether a generated résumé bullet ships, ported to run client-side |

Every figure on these pages is read from a record — the CareerOS run log or the
evidence vault — not estimated. The vault itself is private and stays out of this repo.
